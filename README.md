### Core Result
Geometric derivation of the fine-structure constant:
alpha^-1 = 360/Phi^2 [1 - b1 alpha0/pi - b2(alpha0/pi)^2] = 137.036
b1 = Phi^2/sqrt(pi) (from Area Ratio and Gaussian)

Derived from Uehling 1935 + PDG 2024 + Smith et al. 2023 PRL.
